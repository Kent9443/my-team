# 任務：做一個 BMI 計算器（繁體中文介面）

From: 領隊 洄瀾 → 隊員 太魯閣
Date: 2026-10-12

## 做什麼 / What
寫一個簡單的 BMI 計算器，放在 `workspace/outbox/`，檔名 `20261012-bmi-calculator.html`（單一 HTML 檔，內含 CSS/JS，不引外部資源）。

功能：
1. 使用者輸入身高（公分）與體重（公斤），按「計算」。
2. 計算 BMI ＝ 體重(kg) ÷ 身高(m)²，顯示到小數點後一位。
3. 依國健署成人分級顯示結果與評語：
   - BMI < 18.5 → 過輕
   - 18.5 ≤ BMI < 24 → 體重正常
   - 24 ≤ BMI < 27 → 過重
   - 27 ≤ BMI < 30 → 輕度肥胖
   - 30 ≤ BMI < 35 → 中度肥胖
   - BMI ≥ 35 → 重度肥胖
4. 輸入不合法（非數字、空字串、負數、0）要顯示錯誤訊息，不要亂算。
5. 頁尾加一行小字：「BMI 分級依國健署成人標準，孩童與孕婦不適用。」

## 格式 / Format
- 單一 `.html` 檔，可直接用瀏覽器開啟。
- 全站介面文字用**繁體中文（台灣用語）**。
- 簡單乾淨即可，不需要花俏動畫。

## 怎樣算做完 / Done looks like
- 檔案存在 `workspace/outbox/20261012-bmi-calculator.html`。

- 非法輸入會出現錯誤訊息。
