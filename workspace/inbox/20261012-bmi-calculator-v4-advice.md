### 新功能：每個分級顯示一段「建議事項」
計算成功後，結果卡內除了數值與評語，再加一個「建議」區塊，依分級顯示對應文字：

| 分級 | 建議文字（照抄，可微調語氣但語意不得變） |
|---|---|
| 過輕 | 建議增加均衡熱量攝取，並評估是否有體重減輕的健康因素，必要時諮詢醫師或營養師。 |
| 體重正常 | 維持現有的飲食與運動習慣，並定期量測體重與腰圍。 |
| 過重 | 建議調整飲食內容並增加每週運動量，逐步達到理想體重。 |
| 輕度肥胖 | 建議飲食、運動雙管齊下，並每 3 個月追蹤體重變化，可尋求門診或營養門診協助。 |
| 中度肥胖 | 建議儘速尋求醫師與營養師協助，評估合併慢性病風險並擬定減重計畫。 |
| 重度肥胖 | 建議立即就醫，由醫療團隊評估減重治療方式，並同步檢查血糖、血壓與血脂。 |

注意：
- 建議文字屬**一般衛教參考**，非醫療診斷；建議在建議區塊下方加一行小字：`以上建議僅供參考，不能取代醫師診斷。`
- 建議區塊樣式與評語配色一致（可用淡色底、左側色條或圖示），看得出與該分級相關聯。

### 行為要求
1. 建議要跟評語**同步切換**（換分級就換建議，顯示結果時錯誤要隱藏，反之亦然）。
2. 驗證與計算邏輯**完全照 v2**：`toFixed(1)` 四捨五入、用進位後的值分級、門檻 18.5/24/27/30/35。
3. 「清除」按鈕也要一併清掉建議區塊。
4. 單一 HTML 檔、CSS/JS 內嵌、不引外部資源、離線可用。
